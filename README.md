# AGE Pinturas — site de pintura industrial

Site estático publicado pelo GitHub Pages em **pintura.agemanutencaoeletrica.com.br**.

- `index.html`: página única. O formulário "Trabalhe com a gente" usa `config.js` do app (repositório `age-alfa-painel`) e grava direto na aba Equipe.
- `obras/`: fotos das obras (sem marcas de clientes).
